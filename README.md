# A-RMD-study-of-hypersonic-particulate-impact-on-a-carbon-carbon-composite-
A repository supplementary to paper titled "A Reactive Molecular Dynamics Study of Dust Nanoparticle Impact on Carbon-Carbon Nanocomposite at Hypersonic Velocities in the Presence of Atomic Oxygen" containing some LAMMPS input scripts and python analysis scripts.

Input file for LAMMPS:
  Impact simulation with an option for energy extraction

Python files:
  1. Analyze_Energy_Partition.py --> Analyze the output from LAMMPS simulation and produce energy partiotion results.
  2. Extraction_ProjectileVelocity_Temperature.py --> Extract temperature and velocity of the impactor at a particular simulation step.
